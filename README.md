# Burga Histories

Pages about the history of Burga (Macedo de Cavaleiros, Bragança, Portugal) and its people.

- [Os onze da Burga na Flandres, 1917–1919](https://tonisaraiva.github.io/BurgaHistories/burga-1917/): the eleven Burga men in the Portuguese Expeditionary Corps in the First World War (Portuguese, French, English).
